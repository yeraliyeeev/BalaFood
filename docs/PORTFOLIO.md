## Résumé description

**BalaFood — Developer and Product Creator**  
Developed a trilingual kindergarten meal-planning product that scales ingredients, builds daily menus, summarizes nutrition, and exports printable plans. Converted the original 30-page Excel workflow into a responsive JavaScript web application containing 381 recipe cards across 14 categories. The spreadsheet version was purchased by more than 35 kindergartens and generated approximately ₸700,000.

## Short portfolio description

BalaFood is a Kazakh-, Russian-, and English-language kindergarten meal calculator. It turns structured recipe-card data into scaled ingredient lists, daily menus, nutrition summaries, and printable documents for groups of up to 500 children.

## Interview talking points

- I began with a practical problem: calculating ingredient quantities and costs for kindergarten menus.
- The first version was a 30-page Excel system, which showed that the problem existed beyond one workplace.
- I transformed the workflow into a searchable browser application in three languages.
- The web version required me to structure hundreds of recipe cards, preserve calculation accuracy, design for nontechnical users, and make exports practical for daily work.
- The project taught me that a useful technical product depends on accurate data, clear interfaces, and feedback from real users.
